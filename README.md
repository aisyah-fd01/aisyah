Branch adalah cabang dari sebuah repository yang digunakan untuk mengembangkan atau mengerjakan perubahan secara terpisah tanpa mengganggu kode utama (main/master).

Dengan branch, kita bisa:
Membuat dan menguji fitur baru.
Memperbaiki bug tanpa mengganggu kode utama.
Bekerja bersama anggota tim dengan lebih aman.
Menggabungkan perubahan ke branch utama setelah selesai menggunakan merge.
